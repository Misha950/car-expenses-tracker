# car-expenses-tracker

Опис проблеми та мети проєкту

Проблема: Власники автомобілів рідко ведуть системний облік витрат на транспорт — заправки, ремонти, ТО та інші витрати фіксуються хаотично або взагалі не фіксуються, через що складно оцінити реальну вартість утримання авто та вчасно помітити зростання витрат.

Мета проєкту: Розробити десктопний застосунок на платформі .NET, який дозволяє власнику авто вести облік заправок, ремонтів/ТО та інших витрат в одному місці, а також переглядати підсумкову статистику й графік витрат за обраний період.

 Основні функції застосунку

1. Облік заправок — дата, кількість пального (л), ціна, пробіг
2. Облік ремонтів та ТО — дата, опис робіт, вартість, дата наступного ТО
3. Облік інших витрат — штрафи, страховка, паркування та інше
4. Підсумкова статистика — загальна сума витрат за обраний період
5. Графік витрат — візуалізація витрат по місяцях та/або категоріях

 Технології

| Компонент | Технологія |
|---|---|
| Платформа | .NET 8 |
| Інтерфейс (UI) | WPF (архітектура MVVM) |
| База даних | SQLite + Entity Framework Core |
| Графіки | LiveCharts2 |
| Тестування | xUnit |
| Логування | запис дій у текстовий файл |

 Етапи розробки (як пройде проєкт)

Проєкт пройде повний цикл розробки програмного забезпечення:
- Аналіз проблеми — визначення потреби (описано вище)
- Формування вимог — список функцій (описано вище)
- Моделювання — структура бази даних (сутності: Заправка, Ремонт/ТО, Інша витрата)
- Проєктування — архітектура застосунку (MVVM: розділення інтерфейсу та логіки)
- Реалізація — написання коду
- Тестування — юніт-тести ключової логіки (розрахунки, валідація)
- Автоматизація перевірок — автоматичний запуск тестів через GitHub Actions
- Журналювання — фіксація дій користувача у файл логів
- Базова перевірка безпеки — усі дані зберігаються локально, без передачі через мережу
