# Car Expenses Tracker

Десктопний застосунок для обліку витрат на автомобіль: заправки, ремонти та ТО, інші витрати, підсумки та графіки за обраний період.

## Мета проєкту

Власники автомобілів рідко ведуть системний облік витрат: заправки, ремонти, ТО та штрафи фіксуються хаотично або взагалі не фіксуються. Через це складно оцінити реальну вартість утримання авто. Наш застосунок збирає всі витрати в одному місці, зберігає їх локально на комп'ютері користувача (без хмари й реклами) і показує підсумки та графіки.

## Основні можливості

- Облік заправок: дата, літри, ціна за літр, пробіг
- Облік ремонтів та ТО: дата, тип, опис робіт, вартість, пробіг, дата наступного ТО
- Облік інших витрат: штрафи, страховка, паркування тощо
- Підсумок витрат за обраний період
- Графік витрат по місяцях і категоріях

## Збирання та запуск

### Що потрібно встановити

- [.NET SDK 10](https://dotnet.microsoft.com/download)
- Git

### Команди

```bash
git clone https://github.com/Misha950/car-expenses-tracker.git
cd car-expenses-tracker
dotnet build
dotnet run --project CarExpensesTracker
```

Після запуску відкриється головне вікно з меню: Заправки, Ремонти/ТО, Інші витрати, Звіти.

### Де зберігаються дані

База даних `app.db` створюється автоматично при першому запуску:

- macOS та Linux: `~/.local/share/CarExpensesTracker/app.db`
- Windows: `%LOCALAPPDATA%\CarExpensesTracker\app.db`

## Стан проєкту

Проєкт у розробці. Готово: документація, модель даних, підключення до бази SQLite, головне вікно з навігацією. У роботі: екрани заправок, ремонтів/ТО та інших витрат, екран звітів з графіком, тести, логування.
