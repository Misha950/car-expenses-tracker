User stories та критерії прийняття

Заправки

User story 1
Як власник автомобіля, я хочу додавати запис про заправку (дата, кількість
літрів, ціна за літр, пробіг), щоб бачити, скільки я витрачаю на пальне.

Критерії прийняття:
- Форма містить поля: дата, кількість літрів, ціна за літр, пробіг
- Загальна сума розраховується автоматично (літри × ціна за літр)
- Поле "дата" за замовчуванням містить сьогоднішню дату
- Без заповнення обов'язкових полів (літри, ціна, пробіг) запис не
  зберігається, під полем показується повідомлення про помилку
- Після натискання "Зберегти" запис одразу з'являється у списку заправок

User story 2
Як власник автомобіля, я хочу редагувати або видаляти вже додану заправку,
щоб виправити помилку введення або прибрати випадковий запис.

Критерії прийняття:
- У списку заправок кожен рядок має кнопки "Редагувати" і "Видалити"
- Редагування відкриває ту саму форму, попередньо заповнену поточними
  значеннями
- Видалення запитує підтвердження ("Ви впевнені?") перед видаленням
- Після редагування/видалення список оновлюється без перезапуску програми

User story 3
Як власник автомобіля, я хочу бачити список усіх своїх заправок,
відсортований за датою, щоб відстежувати історію заправок.

Критерії прийняття:
- Список показує: дату, кількість літрів, ціну за літр, загальну суму,
  пробіг
- Найновіший запис показується першим
- Якщо заправок ще немає, показується повідомлення "Записів поки немає"
  замість порожньої таблиці

Ремонти та ТО

User story 4
Як власник автомобіля, я хочу додавати запис про ремонт або ТО (дата,
тип, опис робіт, вартість, пробіг, дата наступного ТО), щоб не забути,
що і коли робилося з машиною.

Критерії прийняття:
- Форма містить поля: дата, тип (ремонт/ТО), опис, вартість, пробіг,
  дата наступного ТО (необов'язкове)
- Поле "дата наступного ТО" можна залишити порожнім
- Вартість повинна бути додатним числом, інакше запис не зберігається
- Після збереження запис з'являється у списку ремонтів/ТО

User story 5
Як власник автомобіля, я хочу редагувати або видаляти запис про
ремонт/ТО, щоб виправити неточні дані.

Критерії прийняття:
- Кожен запис у списку має кнопки "Редагувати" і "Видалити"
- Видалення підтверджується окремим запитанням
- Зміни зберігаються одразу після натискання "Зберегти"

User story 6
Як власник автомобіля, я хочу бачити список усіх ремонтів/ТО, щоб знати
історію обслуговування автомобіля.

Критерії прийняття:
- Список показує: дату, тип, опис, вартість, пробіг
- Записи сортуються за датою (найновіші зверху)
- Тип запису (ремонт/ТО) візуально відрізняється (наприклад, кольором
  або позначкою)

Інші витрати

User story 7
Як власник автомобіля, я хочу додавати запис іншої витрати (дата, тип,
сума, коментар), щоб враховувати штрафи, страховку, паркування тощо.

Критерії прийняття:
- Форма містить поля: дата, тип (штраф/страховка/паркування/інше),
  сума, коментар
- Тип обирається зі списку (dropdown), а не вводиться вручну
- Сума повинна бути додатним числом
- Поле "коментар" необов'язкове

User story 8
Як власник автомобіля, я хочу редагувати або видаляти запис іншої
витрати, щоб виправити або прибрати помилковий запис.

Критерії прийняття:
- Кожен запис має кнопки "Редагувати" і "Видалити"
- Видалення підтверджується запитом
- Список оновлюється одразу після зміни

User story 9
Як власник автомобіля, я хочу бачити список усіх інших витрат, щоб
розуміти, на що ще йдуть гроші окрім пального і ремонту.

Критерії прийняття:
- Список показує: дату, тип, суму, коментар
- Записи сортуються за датою (найновіші зверху)
